# Modelo Instrutor CNH 2 — Guará Agency

## Conceito
Landing page editorial de direção, com estética original, fundo verde-petróleo, tipografia Space Grotesk e acentos coral. Direção de arte desenvolvida segundo os princípios do plugin Impeccable (modo Persuade): hierarquia clara, percurso personalizado, consistência de tokens, acessibilidade, componentes responsivos e CTA contextual.

Prévia prevista: https://guaraagency-julio.github.io/modelo-instrutor-cnh-2/ 

Para implantar: **Settings → Pages → Source: GitHub Actions**. Workflow presente em .github/workflows/pages.yml, disparado a cada push em main.

## Diferencial de conversão
O diagnóstico interativo "Em qual momento da direção você está?" separa 3 perfis — habilitados sem prática, primeira CNH e aperfeiçoamento — e ajusta proposta, objetivos e contato. Há FAQ, método, modalidades, mapa de município, CTA flutuante e diálogo que monta mensagem personalizada.

Todas as credenciais, locais, preços, serviços, avaliações e imagens finais precisam de validação antes de um uso comercial. Lucas Moraes é fictício; Novo Hamburgo é uma localidade demonstrativa; as fotos PxHere CC0 não mostram o instrutor fictício. Não se anuncia autorização nem afiliação com Detran.
